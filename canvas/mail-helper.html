Desktop Chrome

Fill CVRD Ballot

Android Chrome

  1. Tap Copy bookmarklet below.
  2. Bookmark this page in Chrome.
  3. Open Chrome's Bookmarks, find the bookmark and tap Edit.
  4. Rename it Fill CVRD Ballot.
  5. Replace its URL with the copied code and save.
  6. After Mail In opens a CVRD form, tap the address bar, type Fill CVRD Ballot, and select the bookmark suggestion.
Important: The helper fills ordinary voter/contact information, selects “A. Resident Elector” and “mail it to my residential address,” but it does not tick the eligibility declarations or complete the voter signature.
